撤销 Commit

如果要撤销已经提交的某次 commit，推荐使用 git revert。它会生成一个新的反向提交，保留原来的提交记录，适合已经推送到远程分支的场景。

撤销某一次提交

撤销指定 commit 带来的代码变更。

如果有冲突，解决冲突后继续提交并推送即可。

撤销合并提交

如果要撤销的是 merge commit，需要使用 -m 指定保留哪一侧父提交。常见场景下保留当前分支主线，使用 -m 1。

撤销连续多次提交

如果要连续撤销多次提交，可以先用 --no-commit 把反向变更暂存到工作区，确认无误后再统一提交。

<commit1>..<commit2> 是左开右闭区间：不包含 <commit1>，包含 <commit2>。

Submodule

Submodule 用于在一个 Git 仓库中引用并管理另一个 Git 仓库，适合外部库、公共组件等需要独立版本管理的场景。

添加子模块
